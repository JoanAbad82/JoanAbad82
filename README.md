# Joan Abad

I build practical software tools focused on **automation, data analysis, learning and transparent decision support**.

I like projects that turn complex information into something understandable, testable and useful. My work tends to emphasize reproducibility, clear limitations and practical output over black-box results.

## Selected projects

### 📚 [Repàs Actiu](https://github.com/JoanAbad82/repasactiu)
Bilingual Catalan/Spanish learning platform with study, exam and error-review modes, built around validated educational content and memory aids.

### 🃏 [MTGSynergy](https://github.com/JoanAbad82/mtgsynergy)
Semantic analysis of Magic: The Gathering cards, combining deterministic rules modelling, Oracle text interpretation and explainable card interactions.

### 🔎 [GitHub Hidden Gems](https://github.com/JoanAbad82/github-hidden-gems)
Automated discovery system for finding useful but low-visibility open-source repositories across AI, automation, data analysis and quantitative tools.

### 🛡️ [Master Security Review](https://github.com/JoanAbad82/master-security-review)
Lightweight Windows security review utility designed to produce structured, transparent and easier-to-review reports.

### 🔗 [Affiliate Friction Auditor](https://github.com/JoanAbad82/affiliate-friction-auditor)
Toolkit for identifying unnecessary friction between affiliate content, commercial intent and monetized destinations.

### 🧰 [Open Utility Lab](https://openutilitylab.com/)
Independent collection of practical software utilities with an emphasis on transparent output and local or client-side processing where possible.

## What I care about

- Automation that removes repetitive work
- Data quality and reproducibility
- Explainable software
- Useful educational tools
- Practical experimentation
- Clear separation between evidence, assumptions and conclusions
