## How I work

- Separate evidence, assumptions, and conclusions.
- Prefer reproducible and inspectable workflows over opaque outputs.
- Use deterministic rules when they can replace hidden heuristics.
- Treat untrusted inputs conservatively.
- Keep production, research, and experimental surfaces explicitly separated.
- Document important limitations and failure boundaries.
